## Human Summary

A review session started without a port flag now takes any free loopback port the
operating system picks, so two reviews can run side by side. A port you ask for
explicitly still binds exactly and still fails fast when it is taken. Asking for port
`0` is now a configuration error that exits 2, where it used to be accepted silently.

Deliberate user-visible break: a bare `discuss review.md` no longer lands on port 7777;
`--port 7777` restores the old address exactly. The URL printed at startup and carried
in the `session.started` event is the real bound port. Confirmed live: the old binary
refused to start on a busy 7777, the new one auto-allocated port 60073 and reported it.

Implemented per plan in scope and behavior, with two process divergences. The seam's
first two commits are not individually formatting-clean; by human decision the
formatting fix rides in the final commit, so the branch head and CI are green while the
intermediate history is not bisect-clean. And an earlier version of this report was
superseded and regenerated, because its verification evidence predated staging those
formatting fixes; no source file changed during that repair.

Verification: all 10 acceptance criteria pass against the committed tree, none failed
and none marked not-applicable, with format, lint, build, and test all clean.

Tier 3 detail. The risky change is the default bind address, in the session startup
function `run_review_session`: with no configured port it requests `127.0.0.1:0` and
reads the real port back through the new checked helper `local_addr_or_bind_error`,
replacing a fallback that would have reported port 0. The fixed default `DEFAULT_PORT`
is deleted, removing `discuss::DEFAULT_PORT` from the library's public surface — a
breaking API change. Blast radius: the startup URL of every no-flag session, plus
rejection of `DISCUSS_PORT=0` and a config-file `port = 0`. No stored data, schema,
auth, or route changes. Out of scope: the endpoint map in the startup event, the
startup line wording, multi-listener startup, and the bundled skill.
